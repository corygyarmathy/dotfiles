# Rendering Fixture

Not a garden. This is the tree `garden-preview --fixture` renders: a vault whose only job is to put every element the theme styles onto as few pages as possible, so that a change to the stylesheet can be judged by looking at two screenshots instead of nine.

It is deliberately not the vault, and deliberately not the fixture in `checks/digital-garden.nix`. That one is scoped to the publish boundary and asserts on what it renders; this one asserts nothing and renders everything.
